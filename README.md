### 👋 About

Fullstack developer with ~2 years of production experience, building end-to-end applications with **React/Next.js** on the front end and **Node.js/Python** on the back end. Currently deepening my specialization in **application security and identity (AppSec/IAM)**. It's not "one more technology" to me: it's a career direction, and I want to be the person who builds the system *and* secures it.

All of this (products, study, technical decisions) is documented and version-controlled inside **[FelpsXP](https://felpsxp.com)**, my personal tech ecosystem: a "digital organism" where every repository is one piece of a larger system that keeps leveling up. The architecture and decision-making behind it all is shared publicly in **[felpsxp-architecture](https://github.com/FelpsSousa/felpsxp-architecture)**: code excerpts, diagrams, and real proof of what works, from both private and public projects, without exposing sensitive data or compromising the source products.
