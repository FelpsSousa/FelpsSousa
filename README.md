### 👋 About

Fullstack developer with ~2 years of production experience, building end-to-end applications with **React/Next.js** on the front end and **Node.js/Python** on the back end. I am deepening a specialization in **application security and identity (AppSec/IAM)** as a deliberate career direction: I want to be the person who builds the system *and* secures it.

My products, studies and technical decisions live in **[FelpsXP](https://felpsxp-hub-two.vercel.app/en)**, a personal tech ecosystem where every repository is one piece of a larger system. Every repository records its architecture decisions as ADRs, starts from the same audited base (**[felpsxp-template](https://github.com/FelpsSousa/felpsxp-template)**: CI, secret scanning, security policy, Conventional Commits) and ships through reviewed pull requests. The private products are presented on the **[Hub](https://felpsxp-hub-two.vercel.app/en/projects)** as case pages, without exposing their code.
